# Third-party libraries

The libraries in this directory are bundled so the add-on does not depend on
another installed add-on to provide them.

- LibStub (minor 2), public domain, from the WowAce LibStub project.
- CallbackHandler-1.0 (minor 8), Ace3-style BSD license, from the WowAce
  CallbackHandler-1.0 project.
- LibDataBroker-1.1 (minor 4), public domain, by Tekkub.
- LibDBIcon-1.0 (minor 56), Ace3-style BSD license, from the WowAce
  LibDBIcon-1.0 project.

The BSD license text used by CallbackHandler-1.0 and LibDBIcon-1.0 is retained
as `LICENSE.txt` in each corresponding library directory.
